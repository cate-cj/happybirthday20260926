# Minecraft 11岁生日大冒险 🎮🎂

一个使用外部素材打造的流畅美观的 Minecraft 风格生日庆祝网页动画。

## 文件说明

| 文件 | 说明 |
|------|------|
| `minecraft_birthday_premium.html` | ⭐ 高级版（推荐）— 使用外部素材，GSAP驱动，流畅美观 |
| `minecraft_birthday_animation.svg` | 初版 SVG 动画（纯内嵌，无外部依赖） |
| `minecraft_birthday_animation_enhanced.svg` | 增强版 SVG 动画 |
| `minecraft_birthday_celebration.html` | 初版 HTML 展示页 |

## 高级版使用的外部素材

1. **Google Fonts - Press Start 2P** — Minecraft 风格像素字体（CDN）
2. **GSAP 3.12 (cdnjs)** — 专业动画引擎，提供弹性、物理、时间轴动画
3. **地形纹理** — 由 Canvas 程序化生成的 16×16 像素噪点纹理（草方块/泥土），零外部图片依赖，永不加载失败

## 键盘操作

| 按键 | 功能 |
|------|------|
| ⬅️ ➡️ 或 A / D | Alex 左右移动（带走路摆腿动画、自动转向） |
| ⬆️ / W / 空格 | Alex 跳跃（真实重力物理） |
| Steve | 寿星原地待机，挥手致意 |

### ✨ 动画效果
- **GSAP 时间轴入场**：弹性（elastic/back/bounce）缓动
- **Canvas 粒子系统**：像素烟花（带重力、衰减、发光）+ 五彩纸屑
- **火焰摇曳**：蜡烛火焰高频抖动
- **Steve 待机动画**：呼吸起伏 + 挥手
- **鼠标视差**：Steve 和标题随鼠标轻微移动
- **云朵无限漂移**、**礼物盒摇摆待机**

### 🎮 交互功能
- **⌨️ 键盘控制 Alex** — 方向键/WASD移动 + 空格跳跃，带走路摆臂摆腿动画、跳跃挤压拉伸、朝向翻转；无距离限制，可自由走到蛋糕右侧
- **👦 Steve 寿星** — 原地待机挥手，专注庆祝
- **🌳 贴地橡树** — 树干基部与草皮地面贴齐，枝叶与树干无缝衔接
- **🧨 TNT放烟花** — 点击TNT方块或按钮：引信火花闪烁→TNT抖动报警→跳起爆炸→连发3发高空烟花
- **🎁 寻宝玩法** — Alex靠近礼物盒时自动弹出宝物：💎钻石、⚔️铁剑、🗡️钻石剑、🟢绿宝石、🥇金锭、🔮附魔瓶、🍎金苹果、🛡️盾牌
- **💨 Alex吹蜡烛** — Alex靠近蛋糕时嘴边飘出💨气流，自然吹灭蜡烛
- **⭐ 自然吹蜡烛** — 火苗受扰闪烁→向烛芯收拢→干净消失无形变扭曲；青烟沿S形曲线摇曳散去，烛芯余烬不规则明暗缓缓冷却，可重新点燃
- **🌙 昼夜切换** — 白天↔星空夜晚（方形太阳/月亮变换）
- **🌠 流星雨** — 夜晚每1.5-4秒一颗流星由左上向右下划过，星体在前、发光拖尾拖在后方，25%概率连发形成流星雨
- **🎁 点击礼物盒** — 盖子飞走 + 彩纸喷出
- **💬 对话气泡** — 每5秒自动轮换台词
- **📊 经验条** — 页面底部 MC 风格 XP 条，显示 Lv.11
